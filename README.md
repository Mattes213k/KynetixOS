# kynetixOS

USA 🇺🇸

Welcome to the official repository of **kynetixOS**, an open-source operating system project currently under development.

## ⚠️ Important Notice: Work in Progress

Please note that this project is in its **very early stages of development**. 

* **Not Compiled:** This initial version has not been compiled yet.
* **Non-Functional:** The operating system is currently **not functional** and cannot be run or installed at this moment.

The repository is currently public so that developers, tech enthusiasts, and the community can look at the source code, follow the development process, and see how the foundation of the system is being built.

---

## 🚀 Future Roadmap (What's Coming Next)

In the coming months, a **complete, fully functional version** of kynetixOS will be released! 

* **GSI Support (Generic System Image):** The final release will be distributed as a GSI.
* **Universal Compatibility:** This means it is designed to work across all supported Android devices, making it highly versatile and accessible.
* **Long-Term Development:** Creating a full operating system takes time, and development will actively continue over the next few months to ensure stability and performance.

# kynetixOS

Czechia 🇨🇿

Vítejte v oficiálním repozitáři **kynetixOS**, open-source projektu operačního systému, který je momentálně ve vývoji.

## ⚠️ Důležité upozornění: Projekt je ve vývoji

Upozorňujeme, že tento projekt se nachází ve **velmi rané fázi vývoje**. 

* **Nezkompilováno:** Tato úvodní verze zatím nebyla zkompilována.
* **Nefunkční:** Operační systém je momentálně **nefunkční** a v tuto chvíli jej nelze spustit ani nainstalovat.

Repozitář je momentálně veřejný proto, aby vývojáři, technologičtí nadšenci a komunita mohli nahlédnout do zdrojového kódu, sledovat proces vývoje a vidět, jak se staví samotné základy systému.

---

## 🚀 Budoucí plány (Co chystáme)

V následujících měsících bude vydána **kompletní a plně funkční verze** kynetixOS! 

* **Podpora GSI (Generic System Image):** Finální verze bude distribuována jako GSI.
* **Univerzální kompatibilita:** To znamená, že systém je navržen tak, aby fungoval na všech podporovaných zařízeních s Androidem, díky čemuž bude velmi univerzální a dostupný.
* **Dlouhodobý vývoj:** Vytvoření celého operačního systému vyžaduje čas. Vývoj bude aktivně pokračovat v průběhu několika příštích měsíců, abychom zajistili stabilitu a výkon.
